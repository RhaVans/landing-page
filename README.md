## 🛠️ Tech Stack & Visual Identity

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 (Custom theme: `#020202` void, `#111118` panel, `#4fc3f7` signal cyan)
- **Typography**: Rajdhani (Headings), Inter (Body), JetBrains Mono (Telemetry)
- **Animation**: Framer Motion
- **Icons**: Lucide React
